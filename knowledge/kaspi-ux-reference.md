# UX/UI референс: Kaspi → Реестр операторов

_Пожелание Нурлана (одобрено Русланом): интерфейс и удобство как в Kaspi Магазине/приложении, паттерны 1:1, но в фирменной стилистике SkyWorker. Собрано 2026-09-03._

## Ключевые принципы Kaspi (что копируем)
1. **Мобайл-фёрст, супер-апп-логика.** Всё в одном окне, минимум переходов, простые понятные экраны. Телефон — главный сценарий.
2. **Чистота и один акцентный цвет.** У Kaspi — красный (#F14635) на белом. У нас — тот же приём, но акцент = фирменный цвет SkyWorker (уточнить их палитру/лого).
3. **Крупные карточки в ленте/сетке.** Главное фото сверху, минимум текста, всё «читается» за секунду.
4. **Trust-элементы всегда на виду:** рейтинг (звёзды) + число отзывов, бейджи/галочки верификации.
5. **Поиск сверху + фильтры + сортировка.** Многоатрибутные фильтры — сердце маркетплейса.
6. **Нижняя навигация (таббар)** с иконками: Главная / Поиск / Заявки / Профиль.
7. **Простые формы, 2-3 шага.** Регистрация и заполнение профиля без простыней полей.
8. **Повторяемость паттернов** — одинаковые карточки/кнопки/списки на всех экранах, чтобы снижать когнитивную нагрузку.

## 5 обязательных паттернов маркетплейса (из UX-практик)
- Расширенный поиск с фильтрами по атрибутам
- Постоянные индикаторы доверия (рейтинг/отзывы/верификация)
- Двойной кабинет: для «покупателя» и «продавца»
- Простой онбординг с гостевым просмотром
- Сообщения/связь между сторонами

## Как это ложится на реестр операторов
«Оператор» = «товар/продавец» в Kaspi. «Заказчик» = «покупатель».

**Каталог операторов (лента/сетка карточек):**
- Фото оператора, ФИО, направление(я), регион, рейтинг ★ + отзывы, бейдж «допуск подтверждён».
- Сверху: поиск + фильтры (направление, регион, категория допуска 1/2/3, есть своё оборудование, рейтинг) + сортировка.

**Карточка оператора (как карточка товара Kaspi):**
- Крупное фото/обложка, ФИО, тип (наёмный / услуги / оба).
- Рейтинг + отзывы блоком.
- Направления и навыки (теги).
- Допуски/сертификаты — бейджами со статусом верификации.
- Оборудование (если есть) — модели дронов.
- Портфолио — галерея фото/видео/кейсов.
- Крупная кнопка действия: «Связаться» / «Пригласить».

**Двойной кабинет:**
- Кабинет оператора: мой профиль, портфолио, отклики/приглашения.
- Кабинет заказчика: поиск операторов, мои заявки, избранное.

**Онбординг:**
- Гостевой просмотр каталога без регистрации (чтобы ценность видна сразу).
- Регистрация оператора — короткая анкета в 2-3 шага. Согласие на обработку ПД + маркетинг — галкой.
